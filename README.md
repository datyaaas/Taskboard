# TaskBoard v0.1

## Purpose
TaskBoard is a lightweight CRUD REST API built with FastAPI to create, list, read, update, and delete tasks. It serves as the foundation for a DevSecOps CI/CD pipeline.

## Requirements
- Python 3.11+
- Git
